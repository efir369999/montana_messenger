- [COIN-TX-V2.md](COIN-TX-V2.md): Coin transfer record v2 (MTTX, version 2) -- the seed's own chain on one node
- [COIN-TX-V1.md](COIN-TX-V1.md): Coin transfer record v1 (MTTX) -- the one source of its format
