# Montana — the normative set

Seven documents. They are the protocol; nothing outside them is normative, and nothing inside
them repeats what another one holds.

## Read in this order

| # | Document | What it answers |
|---|---|---|
| 1 | **Montana Constitution** | what this protocol must be, and what may never be traded away |
| 2 | **Montana Canon** | every number, every byte, every domain, every vector |
| 3 | **Montana Consensus** | the TimeChain: how it moves and who moves it |
| 4 | **Montana Value** | what money is and how it moves |
| 5 | **Montana Identity** | what a person is, and what a name is |
| 6 | **Montana Network** | how anything reaches anyone |
| 7 | **Montana App** | where the protocol ends and a client begins |

Start with the Constitution. It carries the document map, so from it every other question has an
address.

Beside the seven stands **Montana Registry** — not an eighth voice but an index: every mechanism
of the set under a permanent number, with its anchors, its derivations, its domains and what its
remaining proof awaits. It is not normative and it is held by the gate of the reference tree,
which refuses a build in which a row and the set disagree.

## The four layers, and the four passes

The core reads in four layers, named and never numbered: **the Kernel** — the grammar that has no
replacement; **the doors** — the tables of functions, of suites and of forms, where a row may be
added at a boundary between eras; **the Decree** — the numbers, in its two blocks, the parameters
the Genesis State Hash binds and the forms a boundary may move; and **the planes** — what the
network publishes of an act, which is the vocabulary and nothing else. Canon names them, holds the
test by which a reader decides where a thing belongs, and states the law of each.

The word `tier` in this project belongs to the four passes made over this set and means nothing
about the layers. A pass is a reading; a layer is a place.

## The rules that hold the set together

1. **A value lives in Canon, in the one block that gives it its layer.** A number outside Canon is a second source of truth, and two sources drift; a number inside it standing in no block, or in two, has no layer and is a defect of the same kind.
2. **One mechanism lives in one document.** A second description of the same mechanism is a defect at the moment it appears, not a summary.
3. **Every layer document carries an observability ledger.** A quantity observable from outside without a row in it is a defect: without a denominator of completeness a new leak passes unnoticed.
4. **Every document opens with Scope and closes with a conformance set.**

## To build from this set

Everything an implementation must reproduce is stated as a conformance item at the end of each
document, and every quantity those items consume is frozen in Canon with its derivation. The
frozen vectors in Canon are the first thing to run against: an implementation that reproduces
them has the hash layer right, and one that does not has it wrong whatever else it passes.

No domain separator stands reserved for a mechanism nobody has written, and no value of this set
awaits anything. One thing is open and the Constitution names it at the front: the constraint set
of the two circuits, an artifact this set binds by its hash rather than by prose, with the
statements it must assert, the format of its description and the verifier that consumes it all
frozen in Canon. Everything else — every value, every layout, every domain, the whole of the wire,
the join, the commitment that carries standing — reaches a mechanism, a derivation, a conformance
item and a vector.

## What is not part of the set

- The build order of the client — twenty-one stages, each with the threshold that makes it provable and the criterion that closes it — lives with the client, deliberately outside this set, and is not normative.

## What guards it

Four tiers run over this directory and block work when they find a defect.

| Tier | Subject | Question |
|---|---|---|
| 0 | the whole, from the top | does every promise reach a mechanism, a derivation and a conformance item |
| 1 | facts about a file | script, typography, a value outside Canon, a layout without invariants, a dangling link |
| 2 | meaning inside a document | contradiction, duplication, an unledgered observable, a claim without proof |
| 3 | between documents | one concept under two words, a promise one document makes and another does not keep, a layout against its design |

A tier that finds something locks the set: until the finding is closed, the only work accepted is
closing it.
